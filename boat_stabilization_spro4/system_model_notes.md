# System Modeling, Linearization & Transfer Function (SPRO 4)

This document outlines the mathematical modeling, Taylor series linearization, and empirical system identification performed for the active boat stabilization system using an airkeel mechanism.

---

## 1. Non-Linear Mathematical Modeling
The boat dynamics were modeled using a lumped parameter approach, treating the hull and airkeel as rigid bodies with negligible coupling between roll and yaw. 

The governing non-linear roll dynamics equation is expressed as:

$$(I_x + \Delta I_x)\ddot{\phi} + K_{\dot{\phi}}\dot{\phi} + K_{\dot{\phi}|\dot{\phi}|}\dot{\phi}|\dot{\phi}| + \rho g \Delta \overline{GM_m}\phi + K_{\phi^3}\phi^3 = \tau_k + \tau_d$$

Where:
* $\phi$ represents the roll angle of the vessel.
* $\tau_k(t)$ is the torque generated by the airkeel (comprising keel geometry, paddling effects, and motor torque).
* $\tau_d(t)$ is the load disturbance torque.

---

## 2. Linearization via Taylor Series Expansion
Because standard linear controllers (like a PID controller) cannot run directly on non-linear systems, the equations were linearized around the equilibrium setpoint ($\phi = 0, \dot{\phi} = 0, \ddot{\phi} = 0$) using Taylor series expansion:

$$f(x) \approx f(\bar{x}) + \frac{df}{dx}\Big|_{x=\bar{x}}(x - \bar{x})$$

* **Simplifications applied:** 
  * Higher-order damping terms ($K_{\dot{\phi}|\dot{\phi}|}\dot{\phi}|\dot{\phi}|\approx 0$) and cubic stiffness terms ($K_{\phi^3}\phi^3 \approx 0$) were dropped near the origin.
  * Partial derivatives were evaluated for keel torque components ($\tau_w$, $\tau_p$) to isolate linear coefficients relating keel angle ($\epsilon$) and hull roll ($\phi$).

---

## 3. Plant Transfer Function & System Identification
Due to the complexity of theoretically calculating every hydrodynamic parameter, the plant transfer function $G_{plant}(s)$ mapping the input keel angle to the output boat roll angle was derived using empirical data:

1. **Experimental Data Collection:** Open-loop step inputs ($5^{\circ}$ to $20^{\circ}$) were applied to the airkeel in a water basin while recording IMU roll data.
2. **MATLAB Processing:** The collected data was detrended, filtered, and processed using MATLAB's **System Identification Toolbox**.
3. **Identified Plant Model:** 
   
   $$G_{plant}(s) = \frac{0.143s^2 - 0.3859s - 0.0176}{s^2 + 0.6278s + 0.04092}$$

* **Key Observation:** The transfer function contains a zero in the right-half plane, confirming the system exhibits **non-minimum phase behavior** (initial tilt in the opposite direction before correcting).

---

## 4. Controller Design & Insights
Using the identified transfer function, closed-loop controllers were structured:
* Evaluated Internal Model Control (IMC) with low-pass filtering for non-minimum phase compensation.
* Implemented digital PID tuning via MATLAB's PID tuner application to achieve stable convergence within operating constraints.
